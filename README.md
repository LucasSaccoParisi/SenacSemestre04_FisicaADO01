## Tutorial (como usar o programa)

1. Baixe o arquivo zip do GitHub
2. Importe o arquivo "FisicaADO.py" para um compilador de python (pode ser Visual Studio, VS Code, ou qualquer compilador de python de escolha).
3. Execute o programa e coloque os seus inputs.
4. Ou abra o terminal e execute o programa por comando `python FisicaADO.py` ou `python {caminho para o arquivo FisicaADO.py}`
5. Após colocar os seus inputs, a janela com os widgets vai abrir.
6. Aproveite!
